# TC5061 - Experimentación Parametrizada y Tracking con MLflow

Este repositorio contiene la instrumentación modular y parametrizada del modelo base para la predicción de calificaciones de comensales en restaurantes. Se traslada el flujo exploratorio a un script ejecutable (`src/train.py`) con control de versiones de experimentos mediante **MLflow Tracking**.
